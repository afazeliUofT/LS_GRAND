# Start here

The precursor at commit `5edb408` is a legitimate positive signal, not a final
physical result.  Its strongest robust evidence was against code-specific
state sweeps on two structured codes.  Its generic OSD comparison was mislabeled
as all-state although the executable configuration used only eight states.
This package repairs that defect and adds more dangerous posterior-pruned and exact state-marginal
code-specific competitors.

Run only the default `gate` profile.  Do not run `stress` until the default run
has been independently adjudicated.
