# Preflight scope

The retained preflight is the package's `smoke` profile.  It verifies package
installation, structured-code construction, orbit algebra, trace generation,
LS-FV/LS-A2, full-state OSD audit, full/posterior-pruned/state-marginal
code-specific baselines, DQPSK, result rendering, hashes, and schema validation.

Its classification is intentionally `INCONCLUSIVE_SMOKE_ONLY`.  No scientific
continue/stop verdict may be inferred from the preflight sample sizes or its
20-MHz stress trace.  Only the default `gate` profile can adjudicate the research
route.
