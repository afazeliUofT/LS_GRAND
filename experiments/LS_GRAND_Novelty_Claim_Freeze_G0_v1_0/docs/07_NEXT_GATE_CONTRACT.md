address:

1. structured codes;
2. optimized event-triggered matched receivers;
3. useful BLER regions and high-percentile work;
4. a defensible physical cycle-slip model; and

pass the gate.  The strongest conventional receiver is allowed the same event
trigger, cached metrics, parallelism assumptions, and code-specific decoder.
