# Patent landscape and limitations

This is a scientific proximity screen, not legal advice.

The frozen search found patent families covering:

- parity-check/FEC-assisted carrier-phase estimation using parallel rotations
  and code evidence;
- LDPC coding and decoding for phase-slip channels;
- coherent optical cycle-slip detection and correction;
- GRAND hardware architectures and universal GRAND decoders; and
- GRAND for higher-order modulation constellations.

The closest phase patent, US9166628B2 / US20150171895A1, is materially relevant:
it applies several phase rotations, evaluates phase/codeword metrics, and uses
FEC-code asymmetry to recover absolute phase.  That does not automatically read
on the narrowed LS-FV/LS-A2 algorithm, but it prevents any assertion of patent
clearance.

Before commercialization or a patent filing, qualified counsel should perform:

1. claim construction for the closest active families;
2. family/status review in target jurisdictions;
3. inventor/assignee and continuation/divisional review;
4. a freedom-to-operate analysis; and
5. a separate patentability search for the final frozen implementation.
