# Allowed and blocked claim language

## Frozen working title

**Sparse Latent-Cause Guessing for Rare Persistent QPSK Phase-State Jumps**

## Allowed primary statement

For a frozen zero-or-one persistent QPSK phase-jump model, we study a code-agnostic latent-cause guessing receiver that globally orders state-conditioned candidate components and invokes an arbitrary code-membership oracle. The practical modes are first-valid decoding and an adaptively invoked two-codeword list with complete state-marginal rescoring. We measure actual noisy rank compression, tail work, and affine orbit safety against matched state-aware receivers.

## Required novelty qualifier

To the best of our knowledge after the frozen scientific search, the identical combination of sparse intra-packet persistent automorphism-component ordering, arbitrary-code membership, adaptive first-valid/L=2 operation, and explicit orbit screening was not found. This is a provisional scientific novelty position, not a patent-validity or freedom-to-operate opinion.

## Blocked language

Do not use any wording equivalent to:

- first code-aided phase-slip correction
- first marginalization over hidden states
- new generic exact stopping theorem
- first GRAND decoder with memory
- first phase-aware GRAND
- field-defining exact LS-GRAND
- practically efficient exact certificate
- general solution to continuous phase noise
- patent clearance
- freedom to operate established
