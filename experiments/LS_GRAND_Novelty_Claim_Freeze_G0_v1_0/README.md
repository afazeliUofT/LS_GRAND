# LS-GRAND Novelty and Claim-Freeze Gate G0 v1.0

This is the next bounded step after commit `ed5a4b4be5dbabeed98691043dd64db6d0415dae`.  It does **not** run
another Monte Carlo campaign.  It freezes the scientifically defensible claims
before further algorithmic investment.

## Purpose

The decisive numerical gate established a real sparse-cause search-coordinate
advantage and a promising first-valid/tiny-list frontier, while rejecting the
current exact certificate as the practical flagship.  This package performs the
required novelty and claim-discipline gate:

1. map each proposed claim to the closest primary literature or patent family;
2. separate known inference/aggregation principles from the remaining narrow
   receiver combination;
3. freeze allowed and blocked language;
4. issue a signed decision record; and
5. authorize exactly one subsequent structured-code, matched-baseline,
   physical-model gate if the narrowed claim survives.

## Expected scientific output

The frozen expected classification is
`PASS_NARROWED_APPROXIMATE_CLAIM_FREEZE`, with these sub-decisions:

- foundational exact-fiber/stopping novelty: **stop as the primary novelty route**;
- current exact certificate as a practical receiver: **stop as the primary route**;
- first-valid/adaptive-L2 orbit-screened latent search: **continue one bounded gate**;
- field-defining program: **not authorized**;
- patent freedom to operate: **not determined**.

The package is a scientific novelty screen, not legal advice, patent validity
analysis, or a freedom-to-operate opinion.

```bash
python -m lsgrand_novelty.cli test --log unit_tests.log
python -m lsgrand_novelty.cli run --profile gate --output-root results --run-name example
python scripts/validate_results.py results/example
```
