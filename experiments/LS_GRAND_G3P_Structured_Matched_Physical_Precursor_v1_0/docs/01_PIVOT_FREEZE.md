# Frozen practical pivot

## Retained mechanism

A persistent ±π/2 state jump can have a short description while forcing the
transmitted word very late in a no-slip reliability ordering. Commit `ed5a4b4`
showed strong actual noisy-rank compression for early and middle slips.

## Practical receiver family

- **Normal path:** frozen code-specific decoder.
- **Trigger:** normalized residual of the decoded no-slip codeword, calibrated
  on independent no-slip frames.
- **LS-FV:** globally likelihood-ordered first valid latent state-word component.
- **LS-A2:** invoke complete marginal rescoring of two distinct valid words only
  when a frozen ambiguity trigger rejects the dominant first component.
- **Exact marginal decoder:** oracle/reference only.
