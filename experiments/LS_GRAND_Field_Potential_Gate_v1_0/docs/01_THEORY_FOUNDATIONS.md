# Theory foundations and precise claims

## 1. Channel and code model

Let \(\mathcal C\subseteq\{0,1\}^n\) be any finite code for which membership can
be tested.  Let \(S\) be a finite latent hypothesis (for example, a QPSK cycle-
slip trajectory), with prior \(\pi_s\).  Given a received vector \(y\), each
state \(s\) induces a one-to-one enumeration of all binary words

\[
  x_{s,1},x_{s,2},\ldots,x_{s,2^n}
\]

in non-increasing state-conditioned likelihood

\[
  w_{s,1}\ge w_{s,2}\ge\cdots\ge 0,
  \qquad w_{s,j}=\pi_s p(y\mid x_{s,j},s).
\]

For Gray QPSK in circular AWGN, inverse rotation makes the two label bits
conditionally independent, so the ordering can be generated by increasing
subset sums of absolute bit LLRs.

## 2. Fiber identity

For a codeword \(c\), define its fiber

\[
  \mathcal F(c)=\{(s,j):x_{s,j}=c\}.
\]

With a uniform codeword prior, its exact marginal likelihood is

\[
  \Lambda(c)=\sum_{(s,j)\in\mathcal F(c)} w_{s,j}
             =\sum_s \pi_s p(y\mid c,s).
\]

Consequently, the first valid witness and the largest single witness generally
solve different problems from marginal ML.  They are exact only under additional
conditions that must be stated and proved.

## 3. Certified finite-queue stopping theorem

After revealing a prefix of every state queue, let

\[
 A(c)=\sum_{(s,j)\ \mathrm{revealed}:x_{s,j}=c} w_{s,j}.
\]

Let \(h_s\) be the next unseen weight in state queue \(s\), or zero if that queue
is exhausted.  Because a fixed state's enumeration is injective, a codeword not
yet revealed in state \(s\) can receive at most \(h_s\) additional mass from
that state.  Thus

\[
 B(c)=\sum_{s:\,c\ \mathrm{not\ yet\ revealed\ in}\ s} h_s
\]

is a valid unseen-mass bound, and

\[
 U(c)=A(c)+B(c)
\]

is an upper bound on \(\Lambda(c)\).  A never-seen codeword has upper bound
\(B_0=\sum_s h_s\).

**Theorem (exact stopping).**  If a revealed codeword \(c^\star\) satisfies

\[
 A(c^\star) > \max\!\left\{B_0,
            \max_{c\ne c^\star,\,c\ \mathrm{revealed}} U(c)\right\},
\]

then \(c^\star\) is the unique marginal-ML codeword.

**Proof.**  \(A(c^\star)\le\Lambda(c^\star)\).  Every revealed rival satisfies
\(\Lambda(c)\le U(c)<A(c^\star)\), and every never-seen rival satisfies
\(\Lambda(c)\le B_0<A(c^\star)\).  Therefore every rival has smaller marginal
likelihood.  \(\square\)

The implementation uses log-sum-exp arithmetic and a strict tolerance to avoid
floating-point tie errors.

## 4. Assumption that must not be hidden

The theorem above presumes that every state hypothesis with nonzero prior has an
instantiated queue, or that omitted hypotheses have an additional rigorously
computed outer-tail bound.  A beam of state paths without such a bound cannot
support an exact certificate.  It may still define a useful approximate decoder,
but it must be labeled accordingly.

## 5. Structural rank separation

Consider \(N=n/2\) Gray-QPSK symbols and one persistent \(90^\circ\) slip after
symbol \(\tau\).  Rotation by one quarter-cycle moves each post-slip label to an
adjacent Gray label; hence the uncompensated hard word differs in one bit per
post-slip symbol in the noiseless limit:

\[
 d_H = N-\tau=\Theta(n)
\]

for an early slip.  A Hamming-weight GRAND order must pass at least

\[
  \sum_{i=0}^{d_H-1}\binom{n}{i}
\]

patterns before reaching that apparent corruption, whereas the single-slip
latent family has only \(1+3(N-1)=O(n)\) hypotheses.  This is a coordinate
separation, not by itself an end-to-end complexity theorem: matched state-aware
OSD may exploit the same structure, and exact certification may dominate the
cost.

## 6. Identifiability limit

Each latent rotation trajectory induces an affine map \(T_s\) on binary labels.
If \(c\in\mathcal C\) and \(T_s(c)\in\mathcal C\) produce the same channel law
under different states, the receiver faces a genuine ambiguity.  The relevant
object is the family of intersections

\[
  \mathcal C\cap T_s(\mathcal C).
\]

The gate enumerates these intersections for small codes and samples them for
larger codes.  Pilot anchoring is treated as a separate design choice rather than
silently assumed.

## 7. What is and is not proved by this package

A successful gate can establish exactness for the frozen finite-state model,
demonstrate a scaling advantage over specified baselines, and identify regimes
with manageable ambiguity.  It cannot establish universal superiority over all
codes, all hidden-state channels, optimized hardware implementations, or all
iterative joint synchronization/decoding receivers.
